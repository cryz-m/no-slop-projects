# No slop

This repository is a personal project for me. In the era of AI, most of the time we tend to forget how important it is to understand what we are doing and how it was done in the past. There're a lot of ideas and problems that are worth taking the time to try the old way.

## Rules
- LLMs must **NOT** be used in the coding of the project.
- Research on the problem must **NOT** use LLMs.
- Each project **must** have at least one trustworthy source of information (call it a paper, a website, ...).
- The problem and the solution **must** be explained by me.
- The programming language is up to me.
- In the search for new problems LLMs can be used in guidance.
- When the project is "finished", an LLM can examine the project and tell me everything that could have been done better.
## Soft rules
Most of the time I'll try to follow these statements, but they can be broken at anytime if the situation needs to:
- Each project will have a two week lifespan. (I already see this one being broken)
- Each project will try to create a paper/document based on what I actually build.
- Being serious.
