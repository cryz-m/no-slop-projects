# No slop

This repository is a personal project for me. In the era of AI, most of the time we tend to forget how important it is to understand what we are doing and how it was done in the past, there's a lot of ideas and problems that are worth the time to try in an "old manner".

## Rules
- LLMs must **NOT** be use in the coding of the project.
- Investigation for the problem must **NOT** use LLMs.
- Each project **must** have at least one trustworthy source of information (called it paper, website, ...).
- The problem and the solution **must** be explained by me.
- The programming language is up to me.
- In the search for new problems LLMs can be used in guidance.
- When the project is "finished", an LLM can examine the project and tell me everything that could have been done better.
